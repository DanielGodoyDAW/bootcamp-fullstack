Ejercicio 7 · Nombrado BEM y nesting
Nivel 3 · Recomendado
Objetivo

Empezar a nombrar clases con más claridad y usar nesting con moderación.
HTML de partida

Crea una página con un bloque tipo tarjeta de curso que incluya:

    título;
    texto;
    enlace;
    variante destacada.

Tarea
Debes:

1. nombrar las clases siguiendo una estructura tipo BEM;
2. tener al menos:
    un bloque,
    dos elementos,
    y una variante;
3. escribir parte del CSS con nesting nativo;
4. mantener el anidado corto y legible.

Restricción

No conviertas el ejercicio en una cadena larguísima de clases ni en anidados profundos.

Observa y comprueba

Revisa:

    si el nombre de cada clase comunica mejor qué papel tiene;
    si el nesting realmente mejora la lectura;
    o si en algún punto solo complica el archivo.

Se considerará bien resuelto si

    las clases tienen una lógica clara;
    la variante se entiende bien;
    y el nesting está usado con mesura.
