En esta hoja veremos los contenidos de la segunda sesión de CSS:

    selectores avanzados y combinadores;
    pseudo-clases y pseudo-elementos;
    box model, dimensiones, overflow y bordes;
    display ;
    Flexbox;
    y una primera toma de contacto con BEM, CSS Nesting y Stylelint.

La hoja está pensada para que practiques con una progresión clara: primero aplicarás
reglas muy concretas y verificables, después resolverás pequeños problemas de
maquetación y, al final, dejarás una interfaz sencilla más ordenada y mantenible.
