Ejercicio 2 · Pseudo-clases
Nivel 1 · Recomendado
Objetivo

Practicar estados de interacción, estructura y formulario.

HTML de partida

Crea una página con:

    dos enlaces;
    dos botones;
    una lista con cinco elementos;
    un formulario con:
        un input de texto,
        un checkbox,
        y un campo desactivado.

Tarea

En styles.css :

1. cambia el aspecto de un enlace con :hover ;
2. cambia el aspecto de un botón con :focus-visible ;
3. resalta visualmente el checkbox cuando esté marcado;
4. da un estilo al campo desactivado;
5. aplica un estilo distinto al primer y al último elemento de la lista;
6. alterna fondo en elementos impares o pares con :nth-child() .

Observa y comprueba

Revisa:

    qué diferencia ves entre :hover y :focus-visible ;
    cómo cambia el formulario cuando un campo está desactivado;
    y qué utilidad real tienen las pseudo-clases estructurales.

Se considerará bien resuelto si

    las pseudo-clases elegidas se aplican correctamente;
    los estados se distinguen con claridad;
    y no desaparece el foco visible.
