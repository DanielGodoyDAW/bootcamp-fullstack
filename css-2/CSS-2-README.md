# CSS — Ejercicios

En esta carpeta guardo ejercicios y prácticas de **CSS-2** del bootcamp.

En esta hoja veremos los contenidos de la segunda sesión de CSS:

    -Selectores avanzados y combinadores;
    -Pseudo-clases y pseudo-elementos;
    -Box model, dimensiones, overflow y bordes;
    -Display ;
    -Flexbox;
    -BEM, CSS Nesting y Stylelint.

## Estructura de aprendizaje

La hoja está pensada para que practiques con una **progresión clara**: 

**Primero** aplicarás reglas muy concretas y verificables 
**Sespues** Resolverás pequeños problemas de maquetación 
**Finalmente** dejarás una interfaz sencilla más ordenada y mantenible.

## Cómo ver los ejercicios
Abre el `index.html` de cada ejercicio en el navegador.  
Si hay un `style.css`, estará enlazado desde el HTML.
