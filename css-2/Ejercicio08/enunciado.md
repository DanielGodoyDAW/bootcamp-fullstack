Ejercicio 8 · Mini interfaz con Flexbox y clases consistentes
Nivel 4 · Recomendado
Objetivo

Integrar lo trabajado en la sesión en una pequeña interfaz coherente.

Enunciado

Crea una página titulada “Panel de cursos disponibles” que incluya:

1. una barra superior con título y enlaces;
2. una fila o rejilla simple de tres tarjetas de curso;
3. un botón o enlace destacado en cada tarjeta;
4. una pequeña zona final de aviso o ayuda.

Requisitos obligatorios

Debes usar:

    selectores avanzados o pseudo-clases al menos en alguna parte;
    bordes, radios y padding con criterio;
    overflow o display en un caso sencillo;
    Flexbox para la barra superior y para distribuir las tarjetas;
    clases con una convención clara;
    nesting en algún bloque si aporta legibilidad.

Criterios de calidad

Se considerará bien resuelto si:

    la interfaz se entiende como una unidad;
    las tarjetas siguen un patrón coherente;
    Flexbox resuelve bien la distribución;
    los nombres de clases son claros;
    y el CSS no parece una suma caótica de reglas.
