Ejercicio 3 · Pseudo-elementos
Nivel 2
Objetivo

Usar pseudo-elementos con una función clara y limitada.

HTML de partida

Crea una página con:

    una lista de tres recursos;
    dos enlaces externos;
    un campo con placeholder ;
    un párrafo destacado.

Tarea

En styles.css :

1. añade un símbolo antes de cada recurso con ::before ;
2. añade una marca visual al final de cada enlace externo con ::after ;
3. cambia el color del placeholder ;
4. cambia el aspecto del texto seleccionado con ::selection .

Restricción

No uses ::before ni ::after para introducir contenido esencial que debería estar en el HTML real.

Observa y comprueba

Piensa:

    qué parte del resultado es decorativa y cuál no;
    si el enlace externo sigue siendo comprensible sin el pseudo-elemento;
    y cuándo un pseudo-elemento ayuda frente a cuándo complica.

Se considerará bien resuelto si

    los pseudo-elementos aportan algo claro;
    no sustituyen contenido importante;
    y el resultado sigue siendo comprensible.
