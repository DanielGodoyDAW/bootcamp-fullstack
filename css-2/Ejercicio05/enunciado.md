Ejercicio 5 · overflow y display
Nivel 2 · Recomendado
Objetivo

Practicar dos propiedades que cambian mucho el comportamiento visual de los elementos.

HTML de partida

Crea una página con:

una caja con mucho texto dentro;
    varios span ;
    varios enlaces o botones pequeños;
    una caja que deba ocultarse.

Tarea

En styles.css :

1. limita la altura de la caja de texto;
2. prueba overflow: auto o overflow: hidden según el efecto que se pida;
3. haz que los span se comporten como inline-block ;
4. oculta una caja con display: none ;
5. compara visualmente un elemento inline , uno block y uno inline-block .

Observa y comprueba

Revisa:

    qué diferencia real hay entre ocultar algo y simplemente dejarlo visible;
    cómo cambia el comportamiento de un span cuando pasa a inline-block ;
    y qué ocurre cuando el contenido desborda.

Se considerará bien resuelto si

    overflow resuelve un caso real;
    display cambia el comportamiento de forma visible;
    y puedes distinguir bien los distintos modos de caja.
