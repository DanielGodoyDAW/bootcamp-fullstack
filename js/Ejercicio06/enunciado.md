Ejercicio 6. Mayor de edad o menor de edad
Declara una variable edad y muestra un mensaje distinto según corresponda:

    si tiene 18 o más: acceso permitido;
    si tiene menos de 18: acceso denegado.

Después amplía el ejercicio añadiendo un segundo dato:

    si además tiene autorización especial ( true o false ).

Define una lógica razonable y exprésala claramente con condicionales.

Requisitos

    Usa comparaciones numéricas.
    Usa al menos un operador lógico.
    Muestra mensajes distintos y comprensibles.

Qué trabajas

    condicionales;
    operadores lógicos;
    diseño básico de reglas.
