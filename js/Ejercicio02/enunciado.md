Ejercicio 2. Comprobación de tipos
Declara al menos cinco variables de tipos distintos y muestra en consola:

    el valor;
    el resultado de typeof .

Condiciones
Incluye al menos:

    un string ;
    un number ;
    un boolean ;
    un valor undefined ;
    un valor null .

Formato orientativo de salida
    Valor: 42 | Tipo: number

Qué trabajas

    observación de tipos;
    uso de typeof ;
    análisis del comportamiento del lenguaje.
