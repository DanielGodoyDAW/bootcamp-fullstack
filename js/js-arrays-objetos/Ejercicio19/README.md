Ejercicio 19. Referencia compartida

Crea un objeto con varias propiedades y asígnalo a otra variable.

Tareas

    modifica una propiedad desde la segunda variable;
    observa qué ocurre al mostrar la primera;
    explica con tus palabras por qué sucede.

Qué trabajas

    referencias;
    mutación compartida;
    comprensión de alias sobre el mismo objeto.
