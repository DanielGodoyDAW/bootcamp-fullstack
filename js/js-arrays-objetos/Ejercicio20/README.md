Ejercicio 20. Copia superficial y límite

Crea un objeto con una propiedad anidada, por ejemplo:

    un usuario con direccion ;
    un producto con fabricante ;
    una película con detalles .

Tareas

    haz una copia con spread ;
    modifica una propiedad simple en la copia;
    modifica también una propiedad anidada;
    observa qué cambios afectan al original y cuáles no.

Qué trabajas

    copia superficial;
    diferencia entre propiedades planas y anidadas;
    comprensión de límites de spread
