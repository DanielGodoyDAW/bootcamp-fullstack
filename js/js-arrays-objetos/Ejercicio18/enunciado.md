Ejercicio 18. Guardar una colección en formato JSON
Crea un array de objetos sencillo. Por ejemplo:

    libros;
    videojuegos;
    tareas;
    cursos.

Tareas

    conviértelo a JSON;
    vuelve a reconstruirlo;
    muestra por consola el primer elemento de la colección reconstruida.

Qué trabajas

    JSON con colecciones;
    arrays de objetos;
    transición entre texto y estructura.
