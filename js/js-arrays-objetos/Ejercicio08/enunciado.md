Ejercicio 8. Datos anidados en una persona

Crea un objeto usuario que incluya:

    nombre
    edad
    direccion como objeto anidado con:
        calle
        ciudad
        codigoPostal
    intereses como array

Tareas

    muestra la ciudad;
    muestra el primer interés;
    cambia el código postal;
    añade un nuevo interés al array.

Qué trabajas

    objetos anidados;
    arrays dentro de objetos;
    acceso a estructuras profundas.
