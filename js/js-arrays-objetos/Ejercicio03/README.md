Ejercicio 3. ¿Array u objeto?

Para cada caso, decide si usarías array, objeto o array de objetos. Después, justifica tu decisión brevemente en comentarios dentro del código o en un texto aparte.

Casos:

1. una lista de nombres de alumnos;
2. los datos de un producto;
3. varias tareas con título y estado;
4. las ciudades visitadas por una persona;
5. un catálogo de películas con título, año y género.

Qué trabajas

    criterio de modelado;
    distinción conceptual entre colección y entidad.
