Ejercicio 7. Lista de videojuegos o películas

Crea un array de al menos tres objetos. Cada objeto debe representar un videojuego o una película e incluir:

    id
    titulo
    anio
    genero
    disponible

Tareas

    muestra el array completo;
    muestra solo el título del segundo elemento;
    muestra si el tercero está disponible o no.

Qué trabajas

    arrays de objetos;
    acceso combinado por índice y propiedad;
    estructura de colección realista.
