Ejercicio 12. Ampliar un array sin modificar el original

Crea un array con tres elementos.

Tareas

    crea un segundo array añadiendo dos elementos más mediante spread ;
    muestra ambos arrays;
    comprueba que el original no ha cambiado.

Qué trabajas

    spread en arrays;
    ampliación de colecciones;
    copia superficial básica.
