Ejercicio 2. Ficha de una persona
Crea un objeto que represente a una persona. Debe incluir al menos:

    nombre;
    edad;
    ciudad;
    experiencia previa en programación;
    lenguaje favorito o de interés.

Tareas

    muestra el objeto completo;
    muestra por separado dos de sus propiedades;
    añade una nueva propiedad después de crearlo.

Qué trabajas

    objetos;
    propiedades;
    acceso y ampliación de estructura.
