Ejercicio 17. Convertir un objeto a JSON y viceversa

Crea un objeto usuario con varias propiedades.

Tareas

    conviértelo a texto JSON con JSON.stringify() ;
    muestra el resultado;
    vuelve a convertirlo a objeto JavaScript con JSON.parse() ;
    comprueba que puedes acceder de nuevo a sus propiedades.

Qué trabajas

    serialización;
    parseo;
    diferencia entre estructura viva y texto JSON.
