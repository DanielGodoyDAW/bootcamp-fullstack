Ejercicio 4. Transformar objetos

Crea un array de objetos productos , donde cada producto tenga al menos:

    nombre
    precio

Tareas

    genera un nuevo array que mantenga los datos originales y añada una propiedad
    precioConIVA ;
    usa una tasa de IVA fija definida por ti;
    muestra el resultado de la transformación.

Qué trabajas

    map() con objetos;
    copia con spread ;
    generación de nuevas versiones.
