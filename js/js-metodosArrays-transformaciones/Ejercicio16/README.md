Ejercicio 16. Primer contacto con Map

Crea una estructura Map que relacione:

    nombre de producto → stock
    o
    nombre de alumno → nota
    o
    nombre de herramienta → categoría

Tareas

    crea el Map ;
    consulta el valor asociado a una clave;
    añade una nueva pareja clave-valor;
    muestra la estructura resultante.

Qué trabajas

    Map ;
    asociaciones clave-valor;
    consulta directa.
