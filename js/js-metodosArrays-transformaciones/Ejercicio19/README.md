Ejercicio 19. Comprobar una transformación sencilla

Crea una función que reciba un array de números y devuelva una nueva colección
transformada, por ejemplo:

    duplicados;
    cuadrados;
    solo pares;
    solo positivos.

Tareas

    ejecuta la función con varios casos distintos;
    usa console.assert() para comprobar resultados esperados;
    incluye al menos un caso borde sencillo.

Qué trabajas

    testing básico de lógica;
    entradas y salidas esperadas;
    verificación simple.
