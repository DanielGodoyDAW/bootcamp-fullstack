Ejercicio 20. Comprobar una función con objetos

Crea una función que trabaje con un array de objetos. Por ejemplo:

    obtener tareas completadas;
    extraer nombres de usuarios activos;
    calcular el total de una cesta.

Tareas

    define una colección pequeña de prueba;
    ejecuta la función;
    comprueba algún resultado esperado con console.assert()

Qué trabajas

    testing básico con estructuras más realistas;
    comprobación de lógica desacoplada del DOM.
