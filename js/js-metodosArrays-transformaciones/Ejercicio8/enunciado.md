Ejercicio 8. Validar con some() y every()

Crea un array de notas numéricas.

Tareas

    comprueba si existe alguna nota suspensa;
    comprueba si todas las notas están aprobadas;
    compara ambos resultados.

Qué trabajas

    some() ;
    every() ;
    diferencia entre existencia parcial y validación global.
