Ejercicio 6. Filtrar objetos

Crea un array de tareas con esta estructura mínima:

    titulo
    completada
    prioridad

Tareas

    obtén todas las tareas completadas;
    obtén todas las tareas con prioridad "alta" ;
    muestra cuántos elementos tiene cada resultado.

Qué trabajas

    filter() con objetos;
    selección múltiple;
    lectura de resultados.
