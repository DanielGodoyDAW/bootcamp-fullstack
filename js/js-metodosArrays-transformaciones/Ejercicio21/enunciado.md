Ejercicio 21. Preparar datos para mostrar una interfaz

Crea un array de objetos que represente una colección, por ejemplo:

    productos;
    películas;
    videojuegos;
    cursos.

Cada elemento debe incluir al menos:

    titulo o nombre ;
    una propiedad numérica;
    una propiedad adicional descriptiva.

Tareas

    genera una nueva colección que adapte esos datos para una posible interfaz;
    por ejemplo, que cada elemento tenga:
        titulo
        subtitulo
        etiqueta

Ejemplo orientativo

A partir de:

{ nombre: "Curso de JavaScript", duracion: 40, nivel: "intermedio" }

podrías construir algo como:

{ titulo: "Curso de JavaScript", subtitulo: "40 horas", etiqueta: "intermedio"}

Qué trabajas

    transformación de datos con intención;
    preparación de información para otro contexto;
    separación entre dato original y dato adaptado.
