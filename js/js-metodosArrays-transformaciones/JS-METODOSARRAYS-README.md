## ejercicios de JavaScript: métodos de arrays, transformación de información e introducción al testing de lógica

En esta hoja vas a practicar cómo recorrer, transformar, seleccionar, buscar, validar y
resumir información a partir de colecciones de datos. La meta no es solo usar métodos
de arrays por sintaxis, sino aprender a elegir la herramienta adecuada según la intención
del problema y empezar a escribir lógica más clara, más reutilizable y más fácil de
comprobar.

## Al finalizar esta hoja deberías ser capaz de:

    distinguir cuándo conviene usar forEach , map , filter , find , some , every o
    reduce ;
    transformar colecciones sin alterar innecesariamente el dato original;
    aplicar una noción básica de inmutabilidad;
    reconocer cuándo una función es más fácil de comprobar porque recibe datos claros y
    devuelve resultados previsibles;
    empezar a comprobar lógica de transformación con entradas y salidas esperadas;
    preparar datos para otros contextos, como renderizado o procesos posteriores;
    utilizar Set para eliminar duplicados en casos sencillos;
    comprender en qué situaciones Map puede resultar útil.
