Ejercicio 17. Modificar sin alterar el original

Crea un array de productos con:

    nombre
    precio

Tareas

    genera una nueva colección con el precio rebajado;
    comprueba que el array original no ha cambiado;
    muestra ambas estructuras.

Qué trabajas

    inmutabilidad;
    transformación sin mutación directa;
    uso combinado de map() y spread .
