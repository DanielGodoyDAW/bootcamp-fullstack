Ejercicio 13. Comprobar si un valor existe con includes()

Crea un array de cadenas de texto, por ejemplo:

    tipos de Pokémon;
    categorías de productos;
    nombres de etiquetas;
    géneros de películas.

Tareas

    comprueba si existe un valor concreto;
    comprueba otro que no exista;
    muestra ambos resultados con mensajes claros.

Qué trabajas

    includes() ;
    pertenencia;
    lectura booleana.
