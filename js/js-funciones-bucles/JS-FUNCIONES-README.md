## Hoja de ejercicios de JavaScript: bucles, funciones y reutilización de lógica

En esta hoja vas a practicar cómo repetir tareas con control, encapsular
comportamiento en funciones y reutilizar lógica sin duplicar código
innecesariamente. La meta no es solo escribir for o declarar funciones, sino empezar a pensar cómo se organiza un programa para que sea más claro, más reutilizable y más fácil de mantener.

## Al finalizar esta hoja deberías ser capaz de:
    usar for , while y for...of con criterio;
    crear funciones declaradas, expresadas y flecha;
    diferenciar parámetros, argumentos y valores de retorno;
    evitar repetir bloques de código cuando una función o un bucle resuelven mejor el problema;
    comprender de forma práctica el alcance de variables;
    empezar a usar callbacks en ejercicios sencillos;
    reconocer closures básicas con sentido útil.
