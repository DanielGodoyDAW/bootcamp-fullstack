Ejercicio 12. Reescribe para mejorar legibilidad

Te dan este código:

    const a = 19;
    const b = true;
    const c = 50;
    const d = 10;
    if (a >= 18 && b) {
    console.log(c - d);
    } else {
    console.log(c);
    }

Reescríbelo para que sea mucho más legible:

    cambia nombres de variables;
    mejora el mensaje de salida;
    mantén la lógica general;
    intenta que otra persona pueda entender el código sin explicación adicional.

Qué trabajas

    legibilidad;
    intención del código;
    buenas prácticas iniciales.
