Ejercicio 3. Conversión y coerción
Crea variables con valores como estos:

    "25"
    "100.5"
    "hola"
    true

Haz pruebas con Number() y muestra el resultado de cada conversión por consola.

Después, observa la salida y responde en comentarios dentro del código o en un pequeño
texto aparte:

    ¿qué valores se convierten correctamente?
    ¿qué valores producen NaN ?
    ¿qué diferencias observas entre convertir un texto numérico y uno no numérico?

Qué trabajas

    conversión explícita;
    coerción;
    interpretación de resultados.
