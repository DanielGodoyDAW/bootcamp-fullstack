Ejercicio 7. Estado de stock
Declara variables para representar:

    nombre de producto;
    cantidad disponible.

Muestra un mensaje distinto según el stock:

    0 → “agotado”;
    entre 1 y 5 → “quedan pocas unidades”;
    más de 5 → “disponible”.

Requisitos

    Usa if , else if y else .
    El mensaje debe incluir el nombre del producto.

Qué trabajas

    rangos numéricos;
    condicionales encadenados;
    mensajes dependientes del estado.
