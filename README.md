```text
bootcamp-fullstack/
├─ html/        # Ejercicios de HTML
├─ css/         # Ejercicios de CSS
```

## Cómo ver los ejercicios
- Abre el `index.html` del ejercicio en el navegador, o
- Usa **Live Server** (VS Code) para recargar automáticamente.
