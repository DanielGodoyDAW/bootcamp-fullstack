# Fundamentos de Java

1. Propósito

En esta hoja vas a practicar los fundamentos básicos de Java necesarios para empezar a construir lógica backend.

Trabajarás:

    estructura mínima de un programa Java;
    package e import ;
    variables y constantes;
    tipos de datos;
    entrada por consola con Scanner ;
    operadores;
    condicionales;
    bucles;
    métodos;
    arrays;
    validación básica;
    comparación correcta de String ;
    separación entre cálculo, validación e impresión.

2. Entrega mínima

Debes entregar un proyecto o archivo Java que incluya, como mínimo:

1. Una clase principal con main .
2. Un package . OPCIONAL, si te da problemas lo vemos.
3. Al menos un import si usas Scanner .
4. Variables con nombres claros.
5. Al menos una constante con final .
6. Entrada de datos por consola.
7. Condicionales.
8. Al menos un array.
9. Al menos un bucle.
10. Métodos separados.
11. Comparación correcta de textos con .equals() .
12. Validaciones básicas.
13. Salida clara por consola.
14. El programa debe compilar y ejecutarse.

## Ejercicios recomendados y evaluables

    4, 5, 6 y 7.
