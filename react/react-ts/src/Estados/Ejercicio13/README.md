ex13 — Montaje libre guiado

Crea un componente pequeño de tema libre que combine varios de los comportamientos trabajados en esta hoja.

Debe incluir como mínimo

    un dato visible;
    un valor numérico;
    un bloque que pueda mostrarse u ocultarse;
    al menos dos acciones distintas;
    alguna diferencia visual según el estado actual.

Entrega

    Componente funcional.
