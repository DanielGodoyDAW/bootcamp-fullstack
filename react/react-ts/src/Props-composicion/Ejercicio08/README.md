Ejercicio 8. Comparar props normales y children

Crea dos componentes distintos para mostrar una tarjeta informativa.

Opción A

Un componente InfoCard que reciba por props:

    title
    description

Opción B

Un componente InfoCardContainer que reciba:

    title
    description

Después responde

1. ¿Qué parte resuelve mejor cada enfoque?
2. ¿En qué caso usarías solo props normales?
3. ¿En qué caso te interesa más dejar libertad con children ?

Objetivo

Distinguir entre datos previsibles y contenido flexible.
