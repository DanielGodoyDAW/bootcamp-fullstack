Ejercicio 4. Crear una galería de tarjetas reutilizables

Crea un componente reutilizable llamado TechCard que muestre:

    nombre de una tecnología;
    categoría;
    breve descripción.

Después, monta una pequeña galería con al menos cuatro tarjetas distintas, por ejemplo con tecnologías del bootcamp.

Requisitos

    TechCard debe reutilizarse varias veces.
    Todos los textos deben llegar mediante props.
    El componente no debe tener contenido fijo salvo la estructura.

Objetivo

Afianzar la idea de que el mismo componente puede servir para múltiples datos.
