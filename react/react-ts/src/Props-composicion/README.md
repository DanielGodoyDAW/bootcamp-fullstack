## Props, composición y reutilización de componentes

En esta hoja vas a consolidar uno de los cambios más importantes al empezar a trabajar
con React de forma útil: pasar de componentes rígidos y fijos a componentes
configurables, reutilizables y componibles.

Vas a practicar especialmente:

    el paso de datos mediante props;
    la lectura de props dentro del componente;
    la diferencia entre estructura fija y contenido variable;
    la reutilización de un mismo componente con datos distintos;
    el uso de children como mecanismo de composición flexible.

El objetivo no es solo que “te funcione”, sino que empieces a pensar como alguien que
diseña componentes con intención.

## Competencias que vas a trabajar

Al terminar esta hoja deberías ser capaz de:

    pasar información desde un componente padre a un componente hijo;
    leer props correctamente con props o con desestructuración;
    reutilizar un componente cambiando sus datos de entrada;
    diferenciar entre props normales y children ;
    detectar cuándo un componente está demasiado rígido y conviene parametrizarlo.
