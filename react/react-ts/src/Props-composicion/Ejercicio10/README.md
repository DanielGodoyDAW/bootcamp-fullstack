Ejercicio 10. Error de diseño: demasiados componentes casi iguales

Imagina que alguien ha creado estos componentes:

    ReactCourseCard
    JavaCourseCard
    SpringCourseCard
    SQLCourseCard

Todos tienen exactamente la misma estructura, pero distinto contenido.

Tarea

1. Explica por qué este diseño no es buena idea.
2. Propón una alternativa mejor.
3. Reescribe el enfoque usando un único componente reutilizable.

Objetivo

Afianzar el principio de reutilización mediante props.
