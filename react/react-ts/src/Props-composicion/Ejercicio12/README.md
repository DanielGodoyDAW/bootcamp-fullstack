Ejercicio 12. Reto de ampliación: página modular de bienvenida

Construye una pequeña página modular de bienvenida al bloque de React.

Debe incluir, como mínimo:

    una cabecera;
    un bloque de presentación;
    un bloque de módulos o temas;
    un bloque de normas o consejos;
    un cierre final.

Condiciones

    Debes reutilizar al menos un componente de tarjeta o bloque varias veces con props distintas.
    Debes utilizar al menos un componente contenedor con children.
    La estructura de App debe leerse como una composición clara de piezas.

Qué se espera

Que esta actividad combine todo lo trabajado en la sesión:

    props;
    composición;
    reutilización;
    children ;
    diseño razonable de componentes.
