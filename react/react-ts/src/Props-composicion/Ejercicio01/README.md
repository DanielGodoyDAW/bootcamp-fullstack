Ejercicio 1. Detectar qué parte debería convertirse en props

Lee estas situaciones e indica qué partes deberían mantenerse fijas dentro del componente y cuáles deberían pasar a ser props.

Caso A

Una tarjeta de curso muestra siempre esta estructura:

    título;
    nivel;
    duración;
    botón.

Caso B

Un bloque de aviso muestra siempre:

    un contenedor;
    un título;
    un mensaje;
    un color o tipo visual.

Caso C

Una ficha de alumno muestra:

    nombre;
    email;
    grupo;
    estado de asistencia.

Tarea

Para cada caso:

1. indica qué parte sería estructural y qué parte variable;
2. propón nombres razonables para las props;
3. justifica brevemente por qué esas props mejorarían la reutilización.

Objetivo

Aprender a detectar qué elementos de un componente deben configurarse desde fuera.
