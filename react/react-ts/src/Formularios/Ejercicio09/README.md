ex09 — Inscripción sencilla

Construye una pequeña interfaz de inscripción.

Debe incluir

    un campo para nombre;
    un campo para email;
    una elección entre varias modalidades;
    una casilla de aceptación;
    una acción de envío.

Comportamiento esperado

Al intentar enviar:

    comprueba que los datos mínimos estén completos;
    muestra errores claros si falta algo;
    muestra una confirmación si todo está correcto.

Entrega

    Componente funcional.
    Mensajes visibles de error o confirmación.
