## Formularios

Esta hoja reúne ejercicios prácticos para trabajar con interacción de usuario, recogida de datos y respuestas visuales de la interfaz.

## Indicaciones generales

    Trabaja dentro de tu proyecto del bloque.
    Mantén los componentes simples, legibles y bien estructurados.
    No uses librerías externas.
    Evita soluciones más complejas de lo necesario.
    Si una tarea incluye código de partida, corrígelo o complétalo según se indique.
    Cuando un ejercicio pida mensajes visuales, deben mostrarse en la interfaz.
    Cuando un ejercicio pida estilos, basta con una propuesta mínima funcional.

## Revisión final

Antes de dar por terminada la hoja, comprueba que:

    el código compila;
    los campos se pueden modificar correctamente;
    los botones hacen lo esperado;
    los mensajes aparecen en la interfaz;
    las comprobaciones funcionan;
    los nombres de variables y funciones son claros;
    no has dejado código innecesario.

## Cierre

Completa los ejercicios con soluciones simples, limpias y bien organizadas.
