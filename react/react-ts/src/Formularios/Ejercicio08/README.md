ex08 — Dos momentos de comprobación

Construye dos versiones de una misma interfaz sencilla.

Versión A

    La comprobación se realiza solo al intentar enviar.

Versión B

    La comprobación se muestra mientras se modifica el dato.

Después responde

1. ¿Qué diferencia observas entre ambas versiones?
2. ¿Cuál resulta más cómoda?
3. ¿En qué casos usarías cada enfoque?

Entrega

    Dos componentes o dos variantes claramente separadas.
    Respuestas breves.
