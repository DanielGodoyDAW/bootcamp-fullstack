ex01 — Asociación de acciones

Relaciona cada situación con la forma de interacción que usarías en React.

1. Pulsar un botón para ejecutar una acción.
2. Escribir un dato breve.
3. Enviar un conjunto de datos.
4. Marcar o desmarcar una opción.
5. Elegir una alternativa entre varias.
6. Cancelar una operación.
7. Limpiar información introducida.

Entrega

Para cada caso, indica brevemente:

    qué acción del usuario se produce;
    qué información debería cambiar;
    qué parte de la interfaz debería reaccionar.
