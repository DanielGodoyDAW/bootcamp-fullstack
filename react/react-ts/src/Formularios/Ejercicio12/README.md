ex12 — Panel de acceso

Construye una interfaz algo más completa de acceso, registro o solicitud.

Debe incluir como mínimo

    varios campos;
    una casilla o selector;
    una acción principal;
    comprobación básica de datos;
    mensajes de error o éxito;
    alguna información mostrada en tiempo real.

Criterios de calidad

Se valorará que:

    la estructura sea clara;
    los mensajes sean comprensibles;
    la interfaz reaccione correctamente;
    no haya datos duplicados innecesariamente;
    el componente pueda leerse sin dificultad.

Entrega

    Componente funcional.
