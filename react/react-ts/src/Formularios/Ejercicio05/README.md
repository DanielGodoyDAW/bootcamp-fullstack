ex05 — Envío con comprobación básica

Crea un pequeño formulario con dos campos:

    un nombre;
    un email.

Comportamiento esperado

Al intentar enviarlo:

    comprueba que el nombre no esté vacío;
    comprueba que el email tenga una estructura mínima razonable;
    muestra un mensaje si hay algún problema;
    muestra un mensaje diferente si todo es correcto.

Entrega

    Componente funcional.
    Mensajes visibles en la interfaz.
