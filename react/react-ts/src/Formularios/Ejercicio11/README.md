ex11 — Botón disponible o bloqueado

Crea una interfaz con un campo de email y un botón de acción.

Comportamiento esperado

    El botón debe estar bloqueado mientras el email no cumpla una condición mínima.
    La condición debe calcularse a partir del dato escrito.
    No guardes información duplicada si puedes obtenerla directamente.

Después responde

1. ¿Qué dato se guarda realmente?
2. ¿Qué dato se calcula?
3. ¿Por qué no conviene duplicarlo?

Entrega

    Componente funcional.
    Respuestas breves.
