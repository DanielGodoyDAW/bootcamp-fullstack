ex07 — Ficha editable básica

Crea una pequeña ficha con varios controles.

Debe incluir

    un campo de texto corto;
    un campo de texto largo;
    una selección entre varias opciones;
    una casilla de confirmación;
    una zona de resumen que muestre el estado actual de la ficha.

Entrega

    Componente funcional.
    Resumen actualizado en pantalla.
