# ⚡ Introducción a React

Ejercicios prácticos del bootcamp para aprender React de forma progresiva.

Los ejercicios se encuentras en la carpeta `src/` y están organizados por temas. Cada ejercicio incluye instrucciones detalladas para ayudarte a entender los conceptos clave de React.

En esta seccion seran practicas con Typescript

## 📚 Contenido

- [Ejercicios de Props](./src/Props-composicion/) - Props, composición y reutilización de componentes.
- [Ejercicios de Estados](./src/Estados/) - Manejo de estado y eventos en React.
