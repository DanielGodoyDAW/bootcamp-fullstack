Ejercicio 12. Reto de ampliación: página de bienvenida del alumno

Crea una página de bienvenida para el alumnado del bootcamp con una estructura libre, pero que incluya al menos:

    una cabecera;
    una sección de presentación;
    una sección con recursos o tecnologías;
    una sección con consejos iniciales;
    un pie.

Requisitos

    Toda la interfaz debe estar construida con componentes React.
    El contenido debe estar bien jerarquizado.
    Debes intentar que el código del componente raíz se lea casi como un esquema de la página.

Criterios de calidad

Se valorará especialmente:

    claridad de la estructura;
    nombres de componentes bien elegidos;
    JSX limpio;
    ausencia de errores básicos de inicio.
