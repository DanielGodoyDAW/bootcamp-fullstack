Ejercicio 10. Diagnóstico de errores típicos

Explica qué problema hay en cada uno de estos fragmentos y reescríbelos correctamente.

Caso A
```jsx
function card() {
    return <h2>Tarjeta</h2>;
}
```
Caso B
```jsx
function App() {
    return (
        <h1>Título</h1>
        <p>Texto</p>
    );
}
```
Caso C
```jsx

function FormBlock() {
    return (
        <label for="name">Nombre</label>
    );
}
```
Caso D
```jsx

function Cover() {
    return (
        <img src="cover.jpg" alt="Portada">
    );
}

Objetivo

Reforzar los errores más frecuentes del primer contacto con React.
