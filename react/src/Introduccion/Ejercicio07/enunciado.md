Ejercicio 7. Construir una landing simple por secciones

Crea una pequeña landing de una sola pantalla para presentar un curso ficticio.

La landing debe tener al menos estas secciones:

    cabecera principal;
    bloque “qué aprenderás”;
    bloque “a quién va dirigido”;
    bloque final de llamada a la acción.

Requisitos

    Cada sección debe ser un componente independiente.
    App debe actuar como componente raíz y componer toda la página.
    El código debe leerse de forma parecida a la estructura visual de la interfaz.

Restricciones

    No uses todavía props ni estado.
    No metas más de una responsabilidad importante dentro del mismo componente si puedes separarla con claridad.
    No conviertas cada línea en un componente sin sentido.

Criterios de calidad

Se valorará:

    que la división tenga sentido real;
    que el resultado sea coherente;
    que el árbol de componentes sea comprensible.
