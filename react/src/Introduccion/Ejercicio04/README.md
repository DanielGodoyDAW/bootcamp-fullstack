Ejercicio 4. Crear tu primer árbol de componentes

Crea una interfaz sencilla compuesta por estos componentes:

    Header
    Subtitle
    InfoBox
    Footer

Después, crea un componente App que los utilice todos en el orden que tenga sentido.

Contenido orientativo

Puedes usar un tema como este:

    Header : nombre del bootcamp o del módulo.
    Subtitle : una frase breve sobre lo que estás aprendiendo.
    InfoBox : un pequeño bloque con 2 o 3 líneas explicativas.
    Footer : un texto final corto.

Restricciones

    No metas todo el contenido en un solo componente.
    Cada componente debe tener una responsabilidad clara.
    No uses todavía props.

Objetivo

Practicar la composición de componentes.
