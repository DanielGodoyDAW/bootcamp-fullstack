Ejercicio 9. Proyecto corto: panel informativo del bootcamp

Desarrolla un pequeño panel informativo con contenido relacionado con el bootcamp.

Debe incluir, como mínimo:

    una cabecera principal;
    un bloque con información general;
    un bloque con normas o recomendaciones;
    un bloque con tecnologías del curso;
    un pie final.

Requisitos

    Debe estar dividido en varios componentes con nombres significativos.
    App debe actuar como ensamblador principal de toda la interfaz.
    El resultado debe reflejar que entiendes cómo se organiza una interfaz por componentes.

Criterios de calidad

El trabajo se considerará bien resuelto si:

    el JSX es correcto;
    la estructura es modular;
    los componentes tienen cohesión;
    el árbol de componentes se entiende con facilidad;
    no hay errores básicos como class en lugar de className , etiquetas sin cerrar o nombres de componentes en minúscula.

Criterio extra de calidad profesional

Antes de darlo por terminado, revisa si alguno de tus componentes:

    es demasiado grande y convendría dividirlo;
    es demasiado pequeño y no aporta claridad real;
    tiene un nombre poco descriptivo.
