## Hoja de ejercicios — Introducción a React, JSX y componentes

En esta hoja vas a consolidar los fundamentos de tu primera sesión de React:

    entender la diferencia entre HTML/JavaScript tradicional y React;
    escribir JSX correctamente;
    crear componentes funcionales;
    componer una interfaz a partir de varios componentes;
    reconocer y corregir errores habituales de sintaxis y estructura.

Aquí no vas a trabajar todavía con estado, hooks, props avanzadas ni lógica compleja. El
foco está en construir una base sólida para que, a partir de la siguiente sesión, puedas
reutilizar y organizar mejor tus componentes.

## Al terminar esta hoja deberías ser capaz de:

    crear componentes funcionales sencillos;
    escribir JSX válido;
    distinguir entre etiquetas HTML nativas y componentes personalizados;
    organizar una interfaz simple en partes reutilizables;
    detectar errores básicos de JSX y estructura de componentes.
