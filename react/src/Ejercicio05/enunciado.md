Ejercicio 5. Mini pantalla de presentación del módulo

Construye una pequeña pantalla de presentación del módulo de React.

La interfaz debe incluir, como mínimo:

    un título principal;
    una breve introducción;
    una sección con tres bloques o tarjetas;
    un cierre final.

Condiciones

    Cada bloque o tarjeta debe representarse mediante un componente.
    La pantalla completa debe montarse desde App .
    El resultado debe mostrar claramente una estructura modular.

Requisitos técnicos

    Usa JSX correcto.
    Usa nombres de componentes apropiados.
    No repitas código innecesariamente si puedes estructurarlo mejor.
    No uses estilos obligatoriamente, pero la estructura debe ser clara.

Criterios de calidad

Se valorará especialmente:

    la división razonable en componentes;
    la claridad de la jerarquía;
    que el JSX sea correcto y legible.
