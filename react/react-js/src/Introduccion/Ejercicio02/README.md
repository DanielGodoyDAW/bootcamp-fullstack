Ejercicio 2. Pasar de HTML estático a JSX

Convierte el siguiente fragmento de HTML a un componente React funcional llamado
WelcomeCard .

```jsx
<section class="card">
    <img src="https://via.placeholder.com/150" alt="Imagen de bienvenida">
    <h2>Bienvenido al bloque de React</h2>
    <p>Hoy empiezas a trabajar con JSX y componentes.</p>
    <label for="email">Email</label>
    <input id="email" type="email">
</section>
```

Requisitos

    Debes escribirlo como un componente funcional.
    Debe devolver JSX válido.
    Debes corregir los atributos que no sean correctos en JSX.
    Todas las etiquetas deben quedar correctamente cerradas.

Criterios de calidad

Se valorará especialmente que:

    no haya errores de sintaxis JSX;
    el componente tenga un nombre correcto;
    el código sea limpio y legible.
