Ejercicio 8. Fragmentos y elemento raíz

Crea dos versiones del mismo componente llamado Notice .

El contenido debe incluir:

    un título;
    un párrafo;
    una lista de dos elementos.

Parte A

Haz una versión usando un contenedor HTML como elemento raíz.

Parte B

Haz otra versión usando un fragmento ( <>...</> ).

Después responde

1. ¿Qué problema resuelven los fragmentos?
2. ¿En qué casos puede tener sentido usarlos?
3. ¿Qué diferencia práctica hay entre usar un div y usar un fragmento en este caso?

Objetivo

Entender por qué React exige una estructura de salida clara y cómo evitar contenedores
innecesarios.
