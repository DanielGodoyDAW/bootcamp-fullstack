1. ¿Qué problema resuelven los fragmentos?
    Los fragmentos resuelven el problema de tener que envolver múltiples elementos en un contenedor HTML (como un div) cuando no queremos agregar un nodo extra al DOM. 
2. ¿En qué casos puede tener sentido usarlos?
    Los fragmentos son útiles cuando queremos devolver múltiples elementos desde un componente sin agregar un nodo extra al DOM. 
3. ¿Qué diferencia práctica hay entre usar un div y usar un fragmento en este caso?
    La diferencia práctica entre usar un div y usar un fragmento es que el div agregará un nodo extra al DOM, lo que puede afectar el diseño y la semántica de la página.
