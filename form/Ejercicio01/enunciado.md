Ejercicio 1 · Formulario básico de inscripción
Nivel 1 · Recomendado

Objetivo

Practicar la estructura general de un formulario y la elección razonable de tipos de campo.

Enunciado

Crea una página titulada “Inscripción a un taller técnico”.

Dentro de main , construye un formulario para recoger esta información:

    nombre completo;
    correo electrónico;
    teléfono;
    fecha preferida;
    mensaje breve.

Debajo, añade un botón para enviar la inscripción.

Lo que debes decidir tú

Debes decidir:

    qué tipo de input conviene en cada caso;
    qué campos deberían ser obligatorios;
    cómo nombrar de forma coherente id y name .

Requisitos obligatorios

    todos los campos deben tener label ;
    debe haber al menos 4 tipos distintos de input o controles dentro del formulario;
    el botón debe tener un tipo adecuado;
    el formulario debe ser claro y legible.

Observa y comprueba
Cuando lo termines, revisa:

    qué campos has dejado obligatorios y por qué;
    qué habría pasado si hubieras usado text para todos;
    si cada campo transmite claramente qué dato espera.

Se considerará bien resuelto si

    el formulario tiene estructura limpia;
    los labels están bien asociados;
    los tipos de campo son razonables;
    y el resultado se parece a una inscripción real, no a una lista arbitraria de inputs.
