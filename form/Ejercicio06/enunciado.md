Ejercicio 6 · Tabla con encabezados de fila
Nivel 3

Objetivo
Profundizar en el uso de relaciones entre filas y columnas.

Enunciado

Crea una página titulada “Seguimiento semanal del trabajo”.
Dentro de main , crea una tabla donde cada fila represente un área de trabajo del bootcamp o
del proyecto.

Cada fila debe incluir:

    nombre del área;
    estado actual;
    responsable o referencia;
    observación breve.

Lo que debes decidir tú

Debes decidir:

    qué áreas aparecen;
    qué estados utilizarás;
    el contenido concreto de cada fila.

Requisitos obligatorios

    la tabla debe llevar caption ;
    debe tener encabezados de columna;
    la primera celda de cada fila del cuerpo debe actuar como encabezado de fila;
    debes usar scope="row" al menos una vez en cada fila del cuerpo.

Observa y comprueba

Compara mentalmente este ejercicio con el anterior:

    aquí ya no solo hay encabezados de columna;
    ahora cada fila también tiene una referencia fuerte propia.

Se considerará bien resuelto si

    se entiende bien la diferencia entre cabecera de columna y cabecera de fila;
    la tabla gana claridad respecto al ejercicio anterior;
    el uso de scope="row" está bien justificado.
