Ejercicio 10 · Corrección de un formulario defectuoso
Nivel 4 · Recomendado

Objetivo
Detectar errores y tomar decisiones de mejora con criterio.

Enunciado
A partir del siguiente código, crea una versión corregida y mejor construida en tu propio
archivo.

Código de partida
```jsx

<!DOCTYPE html>
<html>
<head>
<title>Formulario</title>
</head>
<body>
<form>
Nombre <input type="text">
Correo <input type="text">
Password <input type="text">
Edad <input>
Web <input>
Acepto condiciones <input type="checkbox">
<button>Enviar</button>
</form>
</body>
</html>
```

Debes corregir obligatoriamente

    idioma del documento;
    metadatos básicos;
    ausencia de label ;
    tipos de input poco adecuados;
    falta de id ;
    falta de name ;
    estructura general pobre;
    falta de validación mínima razonable.

Lo que debes decidir tú

Debes decidir:

    qué validación nativa aplicar;
    qué estructura envolvente dar al contenido;
    cómo mejorar la claridad general del formulario.

Observa y comprueba

Este ejercicio no consiste solo en “arreglar fallos”, sino en detectar por qué eran fallos:

    ¿qué parte afectaba a accesibilidad?
    ¿qué parte afectaba a claridad?
    ¿qué parte afectaba a comportamiento o semántica?

Se considerará bien resuelto si

    la nueva versión es claramente mejor que la original;
    puedes justificar por qué cada cambio mejora el formulario;
    el resultado final podría formar parte de una interfaz real.
