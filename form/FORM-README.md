# Form — Ejercicios y prácticas

En esta carpeta guardo ejercicios y prácticas relacionados con **formularios HTML** 

## Qué se practica aquí
- Estructura de formularios: `form`, `input`, `label`, `textarea`, `select`, `button`
- Tipos de `input` y atributos comunes (`name`, `placeholder`, `required`, etc.)
- Buenas prácticas de accesibilidad (asociar `label` con `for`, etc.)

## Cómo ver los ejercicios
Abre el `index.html` del ejercicio en el navegador.  
Si estás usando VS Code, puedes usar **Live Server** para verlo más cómodo.
