Ejercicio 9 · Diálogo y contenido incrustado
Nivel 3 · Ampliación recomendada

Objetivo

Tomar contacto con dialog e iframe en un contexto simple.

Enunciado

Crea una página titulada “Información práctica del campus”.
Dentro de main , añade:

    un título principal;
    una breve introducción;
    un bloque de aviso importante usando dialog ;
    un recurso externo incrustado usando iframe .

Lo que debes decidir tú

Debes decidir:

    qué contenido tendrá el aviso;
    qué tipo de recurso tendría sentido incrustar;
    qué título accesible necesita el iframe .

Requisitos obligatorios

    el dialog debe contener al menos un texto y un botón;
    el iframe debe incluir title ;
    el contenido debe resultar coherente con la página.

Observa y comprueba
Piensa:

    qué aporta realmente dialog en este contexto;
    qué tipo de recurso externo sí tendría sentido incrustar y cuál no;
    qué ocurriría si el iframe no tuviera title .

Se considerará bien resuelto si

    el conjunto es coherente;
    el uso de dialog no parece arbitrario;
    el iframe está bien identificado y tiene sentido dentro de la página.
