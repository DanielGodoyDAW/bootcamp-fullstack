Ejercicio 8 · Panel de progreso y estado
Nivel 3

Objetivo
Practicar progress y meter distinguiendo bien su función.

Enunciado
Crea una página titulada “Panel de progreso del alumno”.

Dentro de main , añade una pequeña vista de seguimiento que muestre:

    progreso de dos tareas o bloques;
    dos mediciones o indicadores de estado.

Lo que debes decidir tú
Debes decidir:

    qué datos representan avance real y cuáles representan una medida dentro de un rango;
    qué textos o labels necesita cada elemento;
    qué valores usar.

Requisitos obligatorios

    debes usar al menos 2 elementos progress ;
    debes usar al menos 2 elementos meter ;
    cada uno debe tener un texto asociado que explique qué representa;
    los datos deben ser coherentes.

Observa y comprueba

Cuando termines:

    cambia algún valor y observa si sigue teniendo sentido;
    comprueba si has usado progress y meter con diferencias reales, no como si fueran
intercambiables.

Se considerará bien resuelto si

    la página deja claro qué es avance y qué es medida;
    las etiquetas explican el valor de cada elemento;
    el conjunto parece un pequeño panel útil, no una demo sin contexto.
