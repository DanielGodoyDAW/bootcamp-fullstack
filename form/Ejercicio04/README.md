Ejercicio 4 · Formulario de búsqueda y filtros
Nivel 2

Objetivo
Practicar formularios orientados a consulta y filtrado.

Enunciado
Crea una página titulada “Buscador de cursos”.

Dentro de main , construye un formulario para filtrar cursos usando esta información:

    palabra clave;
    categoría;
    duración máxima;
    fecha de inicio;
    una condición adicional a tu elección relacionada con el curso.

Lo que debes decidir tú

Debes decidir:

    qué tipos de campo son más adecuados;
    si la condición adicional debe resolverse con una casilla, un selector o algún otro control
adecuado;
    si este formulario tendría más sentido con get o con post .

Requisitos obligatorios

todos los campos deben tener label ;
debes usar al menos:

    un campo de búsqueda o texto,
    un selector,
    un campo de fecha,
    un control de selección adicional;

debe haber un botón para aplicar filtros.

Observa y comprueba
Piensa y anota brevemente:

    si este formulario se parece más a una búsqueda o a un alta;
    qué método has elegido y por qué;
    si el conjunto se entiende como herramienta de filtrado real.

Se considerará bien resuelto si

    la página transmite claramente una intención de búsqueda;
    los controles elegidos son coherentes con un filtro;
    no parece simplemente “otro formulario más” reutilizado sin contexto.
