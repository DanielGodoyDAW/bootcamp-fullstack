Ejercicio 7 · Preguntas frecuentes con details y summary
Nivel 3 · Recomendado

Objetivo
Practicar un patrón útil de contenido desplegable.

Enunciado
Crea una página titulada “Preguntas frecuentes sobre el bootcamp”.

Dentro de main , crea una breve introducción y una sección de preguntas frecuentes.

Requisitos obligatorios

    debe haber al menos 4 bloques details ;
    cada bloque debe incluir un summary ;
    las preguntas deben estar relacionadas con el bootcamp, el curso o la inscripción;
    cada respuesta debe tener al menos un párrafo con contenido claro.

Lo que debes decidir tú

Debes decidir:

    qué preguntas son relevantes;
    cómo redactar cada respuesta;
    si conviene agruparlas dentro de una section o usando una estructura más rica.

Observa y comprueba

Fíjate en:

    cómo cambia la lectura cuando el summary es claro o vago;
    si este patrón sirve bien para ayuda o FAQ sin necesidad de JavaScript;
    cómo se entiende la página incluso antes de desplegar nada.

Se considerará bien resuelto si

    las preguntas son creíbles y útiles;
    los summary se entienden por sí mismos;
    la sección parece una ayuda real y no un ejercicio artificial.
