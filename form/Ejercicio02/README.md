Ejercicio 2 · Formulario de creación de cuenta
Nivel 1 · Recomendado
Objetivo
Practicar validación nativa y elección de controles adecuados.

Enunciado
Crea una página titulada “Crear cuenta de alumno”.
Dentro de main , construye un formulario que recoja esta información:

    nombre de usuario;
    correo electrónico;
    contraseña;
    edad;
    enlace a portfolio o perfil profesional;
    aceptación de condiciones.

Lo que debes decidir tú
Debes decidir:

    qué tipos de input convienen;
    en qué campos aplicar validación nativa;
    qué restricciones mínimas deberían existir en nombre de usuario, contraseña o edad.

Requisitos obligatorios

    todos los campos deben tener label ;
    debes usar al menos 4 tipos distintos de input ;
    debes aplicar al menos 4 atributos de validación nativa en total;
    la casilla de aceptación debe estar correctamente asociada a su texto.

Observa y comprueba
Compara el comportamiento de:

    un campo obligatorio frente a uno opcional;
    un campo con minlength frente a otro sin esa restricción;
    un email frente a un text .

Se considerará bien resuelto si

    cada campo está resuelto con un tipo coherente;
    la validación nativa tiene sentido y no está puesta al azar;
    el formulario podría formar parte real de un alta de usuario.

Restricción
No se considerará bien resuelto si todos los campos de texto usan exactamente la misma
solución técnica sin criterio.
