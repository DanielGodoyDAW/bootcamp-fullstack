Ejercicio 6 · Flexbox básico
Nivel 3
Objetivo

Usar Flexbox para resolver alineación y distribución sencilla.
HTML de partida

Crea una página con:

    una barra superior con un logo a la izquierda y tres enlaces a la derecha;
    una fila de tres botones;
    una lista de cuatro tarjetas simples.

Tarea

En styles.css :

1. usa Flexbox para la barra superior;
2. usa Flexbox para la fila de botones;
3. usa Flexbox y gap para las tarjetas;
4. permite que las tarjetas pasen a otra línea si no caben;
5. centra correctamente al menos uno de los bloques usando propiedades de Flexbox.

Observa y comprueba

Piensa:

    qué eje estás usando en cada caso;
    qué hace justify-content ;
    qué hace align-items ;
    y cuándo te conviene flex-wrap .

Se considerará bien resuelto si

    la alineación se resuelve claramente con Flexbox;
    usas gap y wrap con sentido;
    y no recurres a márgenes arbitrarios para simular una distribución.
