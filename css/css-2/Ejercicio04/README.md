Ejercicio 4 · Box model, bordes y dimensiones
Nivel 2 · Recomendado
Objetivo

Comprender visualmente cómo influyen padding , border , margin , tamaño y box-sizing .

HTML de partida

Crea una página con:

    tres cajas con clase compartida;
    un título encima;
    un párrafo explicativo debajo.

Tarea

En styles.css:

1. da a las tres cajas un ancho fijo;
2. aplica padding , border y margin ;
3. haz que una de las cajas tenga más padding ;
4. haz que otra tenga más margin ;
5. aplica box-sizing: border-box de forma global;
6. redondea las esquinas de las cajas.

Observa y comprueba

Comparte mentalmente:

    qué diferencia hay entre aumentar padding y aumentar margin ;
    qué cambia cuando usas border-box ;
    y qué parte del espacio es interior y cuál exterior.

Se considerará bien resuelto si

    se aprecia claramente la diferencia entre padding y margin ;
    las dimensiones tienen sentido;
    y las cajas permiten entender bien el modelo de caja.
