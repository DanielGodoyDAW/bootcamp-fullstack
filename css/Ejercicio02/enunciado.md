Ejercicio 2 · CSS en bloque <style>
Nivel 1 · Recomendado
Objetivo

Practicar CSS dentro del propio documento HTML.

Enunciado

Crea un archivo index.html con:

    un h1 ;
    dos h2 ;
    tres párrafos;
    una lista con tres elementos.

Dentro del head , añade un bloque <style> y aplica estos cambios:

1. todos los h1 y h2 deben compartir la misma familia tipográfica;
2. todos los párrafos deben tener el mismo color;
3. la lista debe tener un color distinto al de los párrafos;
4. el fondo de la página debe ser diferente del blanco puro;
5. uno de los párrafos debe llevar una clase .destacado y tener un color distinto.

Restricción

En este ejercicio no puedes usar archivo externo.

Observa y comprueba

Revisa:

    qué estilos afectan a todos los elementos de un tipo;
    qué estilo solo afecta al elemento con clase;
    y qué ventajas tiene esta forma respecto al CSS en línea.

Se considerará bien resuelto si

    el bloque <style> está correctamente colocado;
    se usan selectores básicos con sentido;
    y ya se percibe una pequeña diferencia entre selector de etiqueta y selector de clase.
