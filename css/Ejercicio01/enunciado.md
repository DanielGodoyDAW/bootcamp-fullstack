Ejercicio 1 · CSS en línea
Nivel 1 · Recomendado
Objetivo

Practicar la forma más simple de insertar CSS: el atributo style .

Enunciado

Crea un archivo index.html con este contenido mínimo:

    un h1 con el texto “Bienvenido al bootcamp”;
    un párrafo con una breve descripción;
    un enlace con el texto “Más información”.

Tarea

Usando solo CSS inline:

1. cambia el color del h1 ;
2. cambia el tamaño del h1 ;
3. cambia el color del párrafo;
4. cambia el color del enlace;
5. añade un color de fondo suave al párrafo.

Restricción

En este ejercicio no puedes usar ni <style> ni archivo externo.

Observa y comprueba
Cuando termines, piensa:

    si esta forma funciona;
    si sería cómoda para una página grande;
    y qué problemas tendría repetir muchos estilos así.

Se considerará bien resuelto si

    todos los cambios están hechos con style="" ;
    el HTML funciona correctamente;
    y puedes identificar por qué esta forma existe pero no es la más cómoda para proyectos
reales.
