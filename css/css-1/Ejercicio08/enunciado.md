Ejercicio 8 · Colores, tipografía y mini interfaz integradora
Nivel 4 · Recomendado.

Objetivo

Integrar en una sola página los contenidos principales de la sesión.

Enunciado

Crea una página titulada “Presentación de una formación” que incluya:

1. una cabecera con título y subtítulo;
2. una breve descripción;
3. tres bloques o tarjetas de contenido;
4. una llamada a la acción final.

Requisitos obligatorios

Debes usar:

    hoja de estilos externa;
    una fuente cargada desde Google Fonts;
    una familia de respaldo;
    al menos cuatro variables CSS en :root ;
    al menos una función CSS útil;
    una paleta coherente de color;
    una diferencia clara entre título, subtítulo, cuerpo y enlace o botón;
    un gradiente lineal en algún punto con sentido.

Criterios de calidad

Se considerará bien resuelto si:

    la página se entiende como una unidad;
    las decisiones visuales son coherentes;
    las variables y funciones están bien integradas;
    y el CSS queda legible y preparado para crecer.
