Ejercicio 5 · Unidades CSS
Nivel 2 · Recomendado
Objetivo

Usar distintas unidades en contextos razonables.

Enunciado

Crea una página titulada “Ficha de curso” con:

    un título principal;
    un subtítulo;
    un párrafo largo;
    una caja de aviso;
    un bloque ancho que haga de contenedor.

Tarea

En styles.css :

1. usa rem en al menos dos tamaños de texto;
2. usa px en un detalle concreto;
3. usa % en una anchura;
4. usa vh o vw en alguna dimensión visible;
5. evita resolver toda la página solo con px .

Restricción
Debes usar al menos cuatro tipos de unidad distintos.

Observa y comprueba
Piensa:

    qué medidas tienen sentido como fijas;
    cuáles funcionan mejor como relativas;
    y si la escala visual de texto y cajas sigue siendo coherente.

Se considerará bien resuelto si

    las unidades están repartidas con lógica;
    no todo depende de medidas rígidas;
    y la interfaz mantiene claridad.
