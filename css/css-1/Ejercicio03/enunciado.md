Ejercicio 3 · Hoja de estilos externa
Nivel 1 · Recomendado
Objetivo

Practicar la forma habitual de trabajo en proyectos reales: hoja de estilos externa.

Enunciado

Crea dos archivos:

    index.html
    styles.css

En index.html incluye:

    un h1 ;
    un subtítulo;
    dos párrafos;
    una caja div con clase .card ;
    un enlace final.

Tarea

Enlaza correctamente styles.css y aplica estos estilos:

1. color general del texto;
2. familia tipográfica del documento;
3. color del título;
4. fondo y espaciado de .card ;
5. color diferente para el enlace;
6. un tamaño de texto distinto entre título, subtítulo y párrafos.

Observa y comprueba

Cuando termines:

    quita temporalmente el <link> y comprueba qué ocurre;
    vuelve a ponerlo;
    verifica que todos los cambios vienen del archivo externo.

Se considerará bien resuelto si

    el archivo externo está bien enlazado;
    los cambios se aplican correctamente;
    y el ejercicio demuestra que entiendes cuál será la forma normal de trabajo a partir de ahora.
