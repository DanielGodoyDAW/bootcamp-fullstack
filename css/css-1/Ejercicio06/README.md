Ejercicio 6 · Variables CSS
Nivel 3 · Recomendado
Objetivo

Empezar a reutilizar valores mediante variables CSS.

Enunciado

Crea una página con:

    una cabecera;
    dos tarjetas de contenido;
    un bloque final de aviso;
    un botón o enlace principal.

Tarea

En styles.css :

1. define en :root al menos estas variables:
    color principal,
    color de texto,
    color de fondo,
    espaciado medio,
    radio de borde;
2. usa esas variables en varios elementos;  
3. evita repetir valores si ya existen como variable.

Restricción

Las variables deben tener nombres comprensibles. No valen nombres vagos como --color1 , --space2 .

Observa y comprueba

Cuando termines:

    cambia un valor en :root ;
    observa qué partes de la interfaz se actualizan;
    valora si el CSS queda más fácil de mantener.

Se considerará bien resuelto si

    las variables tienen sentido;
    se reutilizan de verdad;
    y el CSS resulta más consistente.
