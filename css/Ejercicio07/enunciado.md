Ejercicio 7 · Funciones CSS útiles
Nivel 3
Objetivo

Practicar funciones CSS en casos concretos y no como simple demostración técnica.

Enunciado

Crea una página con:

    un bloque principal;
    un título grande;
    un párrafo descriptivo;
    una caja secundaria.

Tarea

En styles.css :

1. usa calc() en una anchura, una altura o una separación;
2. usa clamp() en el tamaño del título;
3. si quieres, añade min() o max() en otro bloque.

Restricción

Debes poder explicar para qué sirve cada función que has usado.

Observa y comprueba

Revisa:

    si calc() resuelve una necesidad real;
    si clamp() evita tamaños extremos;
    y si el resultado es más flexible que una medida fija.

Se considerará bien resuelto si

    las funciones están bien aplicadas;
    tienen utilidad real en la página;
    y no se usan solo “porque tocaba”.
